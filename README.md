# 國際金融財經日曆 - Google Calendar 雲端自動同步指南 🚀

本專案提供一套**完全自動化、免本機執行、免電腦開機**的雲端同步方案，將全球重要總體經濟數據與金融大事自動同步至您的 Google 日曆。

當設定完成後，腳本將每天自動在 Google 雲端伺服器運行，獲取最新數據，並為您轉換為**繁體中文**，加入國旗 Emoji 與重要度標記。

---

## 💡 核心功能：變更偵測與警示 (Alert) 系統

針對您特別關心的「未來日程時間或數據變更」，系統設計了以下主動警示機制：
1. **變更比對**：每次自動同步時，腳本會將最新的 API 數據與您日曆中已存在的未來事件進行對比，檢測是否有以下變更：
   * **發布時間調整**（如原訂 20:30 延後至 22:00）。
   * **預測值 (Forecast) 修正**。
   * **事件標題/名稱更新**。
2. **視覺化警示 (Alert)**：
   * **事件變更為「警告橘色」**：在 Google 日曆上，變更的事件顏色會立即從預設藍色轉為顯眼的**橘色**。
   * **標題標註 ⚠️**：標題開頭會自動加上 `⚠️ [日程變更]`（例如：`⚠️ [日程變更] 🇺🇸 [美國] 5月核心CPI同比`）。
   * **寫入變更日誌**：點開日曆事件，描述最上方會用醒目的字眼顯示變更時間與具體變更欄位（例如：`• 發布時間由 2026-06-12 20:30:00 變更為 2026-06-12 22:00:00`）。
   * **新增彈出提醒**：自動為該變更事件添加一個「前 15 分鐘」的 Google 日曆彈出視窗通知，確保您不會漏掉。
3. **安靜更新**：如果只是「公佈值 (Actual)」在數據發布後被寫入，這屬於正常數據填補，系統會安靜地更新數值，並將事件顏色轉為**灰色**，代表已完成，保持日曆乾淨。

## 🛠️ 自動化同步設定步驟 (僅需 3 分鐘)

### 步驟 1：開啟 Google Apps Script 平台
1. 用瀏覽器開啟 [Google Apps Script 官方網站](https://script.google.com/) 並登入您的 Google 帳號。

### 步驟 2：複製貼上腳本程式碼

### 步驟 3：首次執行與授權
1. 在編輯器上方中間的函數下拉選單中，確認已選擇 **`syncFinancialCalendar`**。
2. 點擊 **「執行」** (Run) 按鈕。
3. 首次執行需要授予存取日曆的權限，請依照以下 Google 視窗指引操作：
   * 點選 **「審查權限」** (Review Permissions)。
   * 選擇您的 Google 帳戶。
   * 當出現「Google 尚未驗證此應用程式」安全提示時，點擊左下角細字 **「進階」** (Advanced)。
   * 點選 **「前往『未命名專案』(不安全)」** (Go to ... (unsafe))。
   * 點選 **「允許」** (Allow)。
4. 授權完成後，腳本會開始執行。第一次執行會自動在您的 Google 日曆中新建一個名為「**國際金融財經日曆**」的專屬日曆，並寫入所有事件。

### 步驟 4：設定每日/每小時自動更新
設定 Google 雲端自動定時抓取的步驟：
1. 在 Apps Script 網頁的左側邊欄，點擊 **「觸發器」** 圖示（時鐘形狀 ⏰）。
2. 點擊右下角的 **「新增觸發器」** (Add Trigger)。
3. 在觸發器設定視窗中設定：
   * **選擇要執行的功能**：`syncFinancialCalendar`
   * **選擇要執行的部署作業**：`主要`
   * **選擇活動來源**：`時間驅動`
   * **選取時間型觸發器類型**：`日計時器` (如果您要更高頻率，可選 `小時型計時器`)
   * **選取時段**：例如 `上午 6:00 至 7:00` (清晨自動更新)。
4. 點擊 **「儲存」**。

## ⚙️ 如何調整篩選條件？
若要更改篩選的國家或重要性，您不需要下載任何東西，直接在 Google Apps Script 編輯器內修改最上方的 `CONFIG` 變數即可：
* `CALENDAR_NAME`: 日曆的名稱。
* `MIN_IMPORTANCE`: 最低重要性（`2` 代表 2 星及以上，若只想看特大事件可改為 `3`）。
* `COUNTRIES`: 欲同步的國家列表。
* `DAYS_FORWARD`: 同步未來天數（預設為 `14` 天，建議維持在 14-30 天內以維持極速運行）。
